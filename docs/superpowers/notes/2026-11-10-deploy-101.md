## 1. Antes (só leitura)

Pagamentos antigos ligados à comanda **e** à venda ao mesmo tempo (a constraint nova é `not valid` e
não confere essas linhas; esperado 0):

```sql

```

Se aparecer alguma linha, listar e decidir com o dono antes de validar a constraint (passo 4):

```sql

  from public.pagamentos

 order by created_at;
```

Taxas e pagamentos com maquininha/bandeira de outra empresa (o trigger novo só confere linhas novas ou
alteradas nessas colunas; esperado 0 e 0):

```sql
select count(*) from public.cartao_taxas t
  left join public.cartao_maquininhas m on m.id = t.maquininha_id
  left join public.cartao_bandeiras b on b.id = t.bandeira_id
 where m.empresa_id is distinct from t.empresa_id
    or (t.bandeira_id is not null and b.empresa_id is distinct from t.empresa_id);

select count(*) from public.pagamentos p
  join public.cartao_maquininhas m on m.id = p.maquininha_id
 where m.empresa_id is distinct from p.empresa_id;
```

-- 1 linha; convalidated = false até o passo 4

## Rollback

```sql
drop trigger if exists trg_cartao_taxas_mesma_empresa on public.cartao_taxas;
drop trigger if exists trg_pagamentos_maquininha_mesma_empresa on public.pagamentos;
drop function if exists public.fn_cartao_mesma_empresa();
alter table public.pagamentos drop constraint if exists pagamentos_comanda_xor_venda;
-- "pacote_uso: altera": rodar de novo o trecho da policy na seção 7 da 093.
notify pgrst, 'reload schema';
```
